## Instructions (full theme):
0.  install [Tidaluna](https://github.com/Inrixia/TidaLuna) or [Tidalunar](https://github.com/Brskt/TidaLuna) and set tidal player background to "Color" in Display section of settings. install the plugins Radiant-Lyrics and Covertheme
1.  click lyrics only theme file
![image](https://i.imgur.com/s0Dq4d4.png)
2.  click Raw button on top-right
![image](https://i.imgur.com/4v3mQgL.png)
3.   copy link to the raw file's page
![image](https://i.imgur.com/wqP0b3l.png)
4.   paste link in THEMES section of Tidaluna settings
![image](https://i.imgur.com/wxke59e.png)

## Radiant Lyrics Compatibility(lyrics only):
set "text glow" to 10px 
don't set "floating player bar spacing" higher than like 8px
set "player bar tint" to #000000 to match lyrics container
